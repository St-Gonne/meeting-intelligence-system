# Give this to your coding AI

> Help me set up MeetingIntel on this computer. Read AGENTS.md, docs/STATUS.md and
> docs/SETUP.md. Check the machine first, run the demos, then help me install only
> the lanes I need. Use my own folders and accounts; explain the supported recording timezone. Follow PHONE_SETUP.md
> if I want phone recordings. Finish with a short tutorial, command sheet and a
> setup receipt in my private local folder. Tell me which steps actually passed.

Your AI needs terminal/filesystem access to your checkout. It can inspect the
computer, create environments, install the listed dependencies, download permitted
model assets, write local settings and help test the workflow under your direction.
You complete Google/Hugging Face login, model terms and macOS privacy permissions.
Keep tokens out of chat, GitHub and setup receipts. Code can be reviewed without
giving a cloud coding assistant your private recordings or transcripts.

The AI should help with four separate milestones:

| Milestone | Evidence to show you |
|---|---|
| Demo works | Inbox with invented items, terminal help and synthetic Voice ID demo |
| Runtime is ready | Separate environments, downloaded assets, successful model/service preflights |
| Your selected lane works | A short trial with audible capture, a complete transcript, report and brief |
| You can use it alone | A tutorial and command sheet using your actual commands and folders |

Do not describe the whole setup as complete just because a demo opened. If a
package, model digest, device or permission blocks progress, name the exact step
and keep the working parts. A fresh computer may need version-specific fixes;
record them rather than quietly upgrading the analysis model or disabling guards.

The generated tutorial should walk through one normal meeting and one recoverable
failure. The command sheet should fit on one screen or page. Both should say where
raw recordings and results live, what consent starts processing, how phone files
settle, how queue approval differs from retries, and how to stop safely. Do not
put credentials, meeting names or biometric material in those documents.
